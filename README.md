# Auto Switch, descargas

Pre-editor multicámara para Adobe Premiere. Aquí solo están los programas listos para usar.

## Cómo instalarlo

1. Entra a la sección Releases de este repositorio y baja la versión más reciente.
2. Elige el archivo de tu sistema:
   - Windows: `PreEditor_Multicamara-windows-x64.exe`. Si Windows avisa, pulsa Más información y luego Ejecutar de todas formas.
   - Mac (M1 o superior): `PreEditor_Multicamara-macos-arm64.zip`. Descomprime, haz clic derecho sobre la app y elige Abrir. Solo la primera vez.
   - Linux: `PreEditor_Multicamara-linux-x64`.
3. Abre el programa y pulsa Probar mi instalación antes de empezar a editar.

## Si algo falla

Pulsa Guardar diagnóstico para enviar y mándalo junto con una línea de lo que pasó. El diagnóstico no incluye audio ni video.
